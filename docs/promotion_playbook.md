# VibeGames.Ninja First 100 Real Visitors Playbook

This playbook is for attracting real human players and creators to `https://www.vibegames.ninja/` without fake traffic, bots, spam, or deceptive posting.

Use the full arcade link for player posts:

```text
https://www.vibegames.ninja/games
```

Use the homepage when pitching the whole platform:

```text
https://www.vibegames.ninja/
```

## First 100 Visitor Plan

| Channel | Target visitors | Action | Link to use |
|---|---:|---|---|
| Hacker News Show HN | 20-40 | Submit a technical founder story | Homepage |
| Reddit player communities | 20-35 | Share the arcade only where game links are allowed | `/games` |
| Reddit builder communities | 10-20 | Share the creator/upload workflow and tech stack | Homepage or `/upload` |
| itch.io backlinks | 10-25 | Upload one polished HTML5 game and link back to VibeGames | Homepage or `/games` |
| X/Twitter and personal network | 10-20 | Post short clips/screenshots of existing arcade games | Direct game page |
| Indie developer directories | 10-20 | Submit the project as an AI/browser-games platform | Homepage |

Do not post the same message everywhere. Use one tailored post per community and reply to comments manually.

## Submission Links

| Platform | Link | Notes |
|---|---|---|
| itch.io HTML5 docs | https://itch.io/docs/creators/html5 | Supports browser-playable HTML/CSS/JS games. Use ZIP with `index.html` or a single HTML file. |
| CrazyGames developer portal | https://developer.crazygames.com/ | Large browser-game audience. Requires polished game files and a cover image. |
| CrazyGames docs | https://docs.crazygames.com/ | Review engine/SDK expectations before submitting. |
| GamePix developers | https://partners.gamepix.com/developers | HTML5 distribution network for approved games. |
| Newgrounds game submission help | https://www.newgrounds.com/wiki/help-information/content-submission/games-and-movies | Accepts HTML5 ZIP uploads with `index.html` at the ZIP root. |
| Product Hunt new post | https://www.producthunt.com/posts/new | Best after the homepage and top game pages have strong screenshots/social previews. |
| Hacker News submit | https://news.ycombinator.com/submit | Use a concise Show HN title and be ready to answer technical questions. |

## Show HN Draft

Title:

```text
Show HN: VibeGames.Ninja - an arcade for AI-made browser games
```

URL:

```text
https://www.vibegames.ninja/
```

Text:

```text
I built VibeGames.Ninja to make AI-made browser games easier to publish, discover, and improve.

AI tools can now produce small HTML5 games quickly, but getting from "I made this" to a polished game page with creator profiles, ratings, feedback, game jams, and analytics is still clunky. VibeGames is an arcade and publishing platform for those games.

The stack is Next.js, Prisma/Postgres, NextAuth, Cloudflare R2, and sandboxed browser game embeds. I would love feedback on the player experience, upload flow, and what AI game creators need most.
```

## Tracking Checklist

- Check live homepage stats before posting.
- Post one channel at a time so traffic source spikes are easier to understand.
- Use distinct links when useful:
  - `https://www.vibegames.ninja/games?ref=hn`
  - `https://www.vibegames.ninja/games?ref=reddit-webgames`
  - `https://www.vibegames.ninja/?ref=producthunt`
- Record each post URL, posting time, and comments/questions received.
- Watch for real signals: plays, comments, ratings, account signups, upload attempts, and returning visitors.
- Reply manually to every substantive comment during the first 24 hours.

## Launch Order

1. Pick the strongest existing game pages to feature from `https://www.vibegames.ninja/games`.
2. Submit Show HN using the draft above.
3. Post the player-focused Reddit version to one allowed community.
4. Post the builder-focused version to one allowed community.
5. Upload one polished HTML5 game to itch.io and include the backlink template.
6. Share one short X/Twitter thread with direct links to the best game pages.
7. Wait 24 hours, record results, then decide whether Product Hunt is ready.
